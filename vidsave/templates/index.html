vidsave

Local-only saver for Instagram and X/Twitter videos. Nothing leaves this machine except the request to the site itself.

{% if not ytdlp %}
yt-dlp is not installed. Downloads will fail. Run brew install yt-dlp, then restart the server.
{% elif not ffmpeg %}
ffmpeg is not installed. Posts whose audio and video are separate streams will be refused rather than saved silently without sound. Run brew install ffmpeg.
{% endif %}
  • Supported: instagram.com/reel|reels|p|tv/… and x.com / twitter.com/<user>/status/…
  • Private, deleted, and age-restricted posts will fail with a plain reason — they never silently produce an empty file.
  • The file is deleted from the server's temp folder the moment it finishes sending to you.
  • For your own viewing. Reposting or redistributing is on you, not the tool.
